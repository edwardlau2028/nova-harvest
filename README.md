Nova Harvest — an original top-down arena survival game. Fly a harvester ship, catch falling star shards, chain combos up to 5×, dodge wisps (Drifters, dashing Darters, splitting Splitters), dash through danger and fire the Nova. Win at 5,000 points, then keep playing endlessly.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Controls: WASD/arrows or mouse to steer, Space/Shift to dash, E to fire the Nova, P to pause, M to mute.
